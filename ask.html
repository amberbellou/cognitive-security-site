Ask the Evidence

Ask a question; get back the exact passages from the collection that address it, each with its source, year, and page. By default this is verbatim retrieval — no AI writes the answers, so nothing can be made up. Optionally, switch on AI synthesis to have Claude compose an answer from the retrieved passages only, every sentence cited back to the verbatim passage it came from. For the curated cross-paper argument, see the Synthesis page.

Every retrieved passage below is a verbatim string from the corpus — either a machine-verified quote from a paper (with page number) or curated metadata from the catalog. Retrieval is ranked keyword search (BM25) running entirely in your browser; in the default modes your questions never leave it. If you switch on AI synthesis, your question and the retrieved passages (nothing else) are sent to Anthropic’s API with your own key; the composed answer is labeled as AI-written and must cite the verbatim passages, which are always displayed for checking.

Team members only: paste a fine-grained GitHub personal-access token (read-only “Contents” permission on the private repo). It is stored only in this browser (localStorage) and used solely to fetch the paper text from the private repository.

Create a key at console.anthropic.com → API keys. It is stored only in this browser (localStorage) and sent only to api.anthropic.com with your questions. The composed answer is instructed to use the retrieved passages as its sole source and to cite them sentence by sentence — always check the citations against the verbatim passages shown below it.
